Your project, in plain English

Make a promotional website for a band, author, film star or influencer. Show their work, products and news, with a contact form. Put the latest work on the home page.

The brief asks for at least five pages, plus planning, publishing, testing and feedback. These lessons build the coding skills.

Before you begin

Work in VS Code and preview in its integrated browser. Your folder is college OneDrive → L2 Digital → Web Development. No experience needed. The example client, Alex Rivers, is fictional: practise on Alex, then use your own client.

Each lesson takes about 20–35 minutes, or longer at the start. Short clickable questions give feedback. A wrong answer is a clue: try again.

How to use each lesson

  1. Read the short explanation and diagram.
  2. Try the interactive demo, then your own files.
  3. Check the result in your browser.
  4. Apply it to your own website.

Save with Ctrl+S (Windows) or Cmd+S (Mac). If the preview does not update, use its Reload button.

Keep the learning yours

Use the examples to practise. Your assessed site needs your own planning, content, decisions and explanations. If you use AI, ask for a hint or feedback, then try the fix yourself.

This is a front-end project. Forms and products can be prototypes. Sending messages and taking payments need a back end, which is an optional extension.
