Style with CSS

CSS means Cascading Style Sheets. One stylesheet can give all your pages a consistent look.

The content is there. Now choose its appearance.

Your page already works because the browser gives headings, paragraphs and links default styles. CSS lets you change those defaults. The HTML still says “this is a heading”; CSS can say “make headings this colour”.

A stylesheet is a text file full of rules. You will link it to your HTML, then edit one rule at a time. Keep the HTML and CSS tabs open in VS Code so you can compare them with the integrated preview.

Why keep CSS separate from HTML?

Imagine your client asks for a different heading colour across five pages. If every page has its own styling, you could miss one. When all five pages link to one stylesheet, you can change the shared rule once and check the result everywhere.

Separating content and presentation also makes each file easier to read: find the words in HTML and their appearance in CSS. A consistent style helps visitors recognise the same website as they move between pages.

1. Link a stylesheet

  1. Create a folder called css beside your HTML files.
  2. Inside it, create style.css.
  3. Add the following line inside head in both HTML pages, just before </head>.

Both HTML files — add inside head

<link rel="stylesheet" href="css/style.css">

rel="stylesheet" identifies the linked file as CSS. The href path must match its location. Write CSS rules directly in the CSS file, without <style> tags.

First, prove the CSS file is connected

Put just this rule in the empty css/style.css file:

css/style.css — first connection check

h1 {
  color: purple;
}

Save and look at Home. The main heading should turn purple; its words should stay the same. Change purple to teal and check again. The rule changes appearance, while HTML holds the words.

If nothing changes, check the filename and the link inside your HTML head before going further.

2. Read a CSS rule

A rule explained

.card {
  padding: 1rem;
}

.card is the selector: it selects elements with class="card". Inside the braces, padding is the property and 1rem is its value. The colon separates them; the semicolon ends the declaration.

p selects all paragraphs. .hero selects a class. #contact-form selects an element with that id. Keep selectors simple. When equally specific rules compete for the same property, the later rule wins; more specific selectors can override earlier general styles. Some values, such as text colour, are inherited from a parent.

3. Add your first styles

Replace your short connection-check rule with this complete starting stylesheet in css/style.css. Save and check Home. You do not need to memorise every rule: start by finding color, background-color and font-size.

css/style.css — initial complete file

* {
  box-sizing: border-box;
}
body {
  margin: 0;
  font-family: Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
  color: #18343b;
  background-color: #f7f8f3;
}
header, main, footer {
  max-width: 1100px;
  margin: 0 auto;
  padding: 1rem;
}
a {
  color: #00635b;
}
a:focus-visible, button:focus-visible,
input:focus-visible, textarea:focus-visible {
  outline: 3px solid #a34400;
  outline-offset: 3px;
}
h1, h2, h3 {
  line-height: 1.2;
}
h1 {
  font-size: 2.5rem;
}
.hero {
  background-color: #e0f0e9;
  padding: 1.5rem;
  margin-bottom: 2rem;
  border-radius: 12px;
}
.card {
  background-color: white;
  padding: 1rem;
  border: 1px solid #a4b9b2;
  border-radius: 8px;
}
img {
  max-width: 100%;
  height: auto;
}

rem measures against the root font size; 1rem is usually 16 pixels at default settings. px means CSS pixels. You do not need to calculate every size: try a value and check readability.

max-width limits wide content. margin: 0 auto centres the container when there is spare width. max-width: 100% lets an image shrink to its container; height: auto keeps its proportions.

4. Understand the box model

margin — space outside the border
border — the edge
padding — space inside the edge
content — text or image

box-sizing: border-box includes padding and borders in a declared width. The * selector applies it to all elements. This makes sizing easier to manage.

Try it

  1. Change the hero background to #fff0ce.
  2. Change its padding from 1.5rem to 2rem.
  3. Compare padding with changing margin-bottom.
  4. Open Contact. It should use the same font and page spacing.

Expected result: both pages share styles. Changing padding moves content away from the hero’s edge; margin changes the space outside it.

If the CSS does not appear

Check that both HTML files link to css/style.css, the CSS file is saved, and braces/colons are present. Make one obvious change, such as the background, to check the link.

Does .card select a tag named card?

No. The dot means a class selector. It selects elements such as <article class="card">.

Why readability and keyboard focus matter

Accessibility means making your site usable by people with different abilities and ways of browsing. Pale text on a pale background can be difficult to read, especially for someone with low vision. Choose a clear contrast between text and its background, and keep body text comfortable to read.

Some people navigate with a keyboard rather than a mouse. A visible focus outline shows which link or field they are on. Keep that outline and test with Tab. Do not rely on colour alone to communicate something important: links, errors and selected answers need other clues, such as an underline or explanatory text.

Apply it to your project

Use your planned colours and fonts. Keep body text readable and links recognisable. Use spacing to separate related groups. Test keyboard focus with Tab. Record why these choices suit your client and audience.

Stretch: a background image

A decorative hero background can use background-image: url("../images/album.svg"); and background-size: cover;. CSS paths start from the CSS file, so ../ goes up one folder. Use a separate empty decorative area or a solid text panel so text remains readable. Keep meaningful images as HTML images with alt text.

Spot the error

Why is the card background not changing?

The stylesheet is linked correctly and saved. This HTML has class="card", but the CSS below does not select that class.

Broken example — find the mistake

<article class="card">
  <h2>Morning Light</h2>
</article>

/* In css/style.css */
card {
  background-color: lightblue;
}
Need a hint?

A dot selects a class; a hash selects an id. What kind of label is used in the HTML?

What is missing from the CSS selector?

Choose the fix. If it is not right, read the clue and try again.

Show the corrected code and explanation
.card {
  background-color: lightblue;
}

Replace the CSS rule with this one and keep the HTML unchanged. Save and check whether the card changes colour.
