Step 4 of 7Style

Style with CSS

CSS means Cascading Style Sheets. One stylesheet can give all your pages a consistent look.

HTML holds the words. CSS decides how they look.

1. Link a stylesheet

  1. Make a folderCall it css, beside your HTML files
  2. Make a fileInside it, create style.css
  3. Add the linkIn the head of both pages

Both HTML files — add inside head

<link rel="stylesheet" href="css/style.css">

The href must match where the file is. No <style> tags inside a CSS file.

Prove it is connected

Put just this rule in css/style.css:

css/style.css — connection check

h1 {
  color: purple;
}

Expected result: the Home heading turns purple. Change purple to teal to check again. Nothing happens? Check the filename and the link.

2. Read a CSS rule

Try it: change a rule

Edit the code

Result

Change purple to teal. Change 1.2rem to 2rem. If two rules clash, the later one wins.

3. Add your first styles

Replace the test rule with this starter stylesheet. Save and check Home.

css/style.css — initial complete file

* {
  box-sizing: border-box;
}
body {
  margin: 0;
  font-family: Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
  color: #18343b;
  background-color: #f7f8f3;
}
header, main, footer {
  max-width: 1100px;
  margin: 0 auto;
  padding: 1rem;
}
a {
  color: #00635b;
}
a:focus-visible, button:focus-visible,
input:focus-visible, textarea:focus-visible {
  outline: 3px solid #a34400;
  outline-offset: 3px;
}
h1, h2, h3 {
  line-height: 1.2;
}
h1 {
  font-size: 2.5rem;
}
.hero {
  background-color: #e0f0e9;
  padding: 1.5rem;
  margin-bottom: 2rem;
  border-radius: 12px;
}
.card {
  background-color: white;
  padding: 1rem;
  border: 1px solid #a4b9b2;
  border-radius: 8px;
}
img {
  max-width: 100%;
  height: auto;
}
Handy values
You writeIt means
1remAbout 16px. Based on the root font size.
margin: 0 autoCentre a box that has a max-width.
max-width: 100%; height: autoAn image shrinks to fit and keeps its shape.

4. Understand the box model

Try it: padding, border and margin

Content: Morning Light

Neighbour box: watch the gap

Padding grows inside the border. Margin pushes the neighbour away. box-sizing: border-box (the * rule) keeps padding and border inside the width.

Try it

  1. Set the hero background to #fff0ce.
  2. Change its padding from 1.5rem to 2rem.
  3. Change margin-bottom and compare.
  4. Open Contact. It shares the font and spacing.

Expected result: both pages share the styles. Padding moves content away from the hero’s edge. Margin changes the space outside it.

If the CSS does not appear

  • Both pages link to css/style.css.
  • The CSS file is saved.
  • Braces and colons are in place.

Spot the error

Why is the card background not changing?

The stylesheet is linked and saved. The HTML has class="card", but the CSS does not pick that class.

Broken example — find the mistake

<article class="card">
  <h2>Morning Light</h2>
</article>

/* In css/style.css */
card {
  background-color: lightblue;
}
Need a hint?

A dot picks a class. A hash picks an id. Which does the HTML use?
