Pages with meaning

Semantic HTML uses elements whose names describe their purpose. It gives your page a clear structure for people and software.

Semantic means “about meaning”. A nav says “these are menu links”. A div says nothing.

1. Name the parts of a page

Try it: see the tags

Edit the code

Result

Change one article to a div (both tags). Its label disappears: a div has no meaning.

Why bother?

Screen readers use these parts as landmarks. People can jump straight to the menu or the main content.

2. Structure your home page

Replace everything between <body> and </body> with this. Keep the head and your album image.

index.html — replacement body content

<header>
  <p>Alex Rivers • Indie music</p>
  <nav aria-label="Main navigation">
    <a href="index.html" aria-current="page">Home</a>
    <a href="contact.html">Contact</a>
  </nav>
</header>
<main>
  <h1>Meet Alex Rivers</h1>
  <p>Alex is a fictional musician who makes upbeat indie music.</p>
  <section class="hero">
    <h2>Latest release: Morning Light</h2>
    <p>A new collection of songs about fresh starts.</p>
    <img src="images/album.svg"
         alt="Morning Light album cover: a yellow sun above teal hills"
         width="600" height="400">
  </section>
  <section>
    <h2>Explore the music</h2>
    <div class="cards">
      <article class="card">
        <h3>Morning Light</h3>
        <p>An upbeat album for a new day.</p>
      </article>
      <article class="card">
        <h3>City Walk</h3>
        <p>A single inspired by evening walks.</p>
      </article>
      <article class="card">
        <h3>Live Sessions</h3>
        <p>Acoustic versions of favourite tracks.</p>
      </article>
    </div>
  </section>
</main>
<footer>
  <p>Alex Rivers — fictional practice website.</p>
</footer>

class="card" lets CSS style a group. aria-label names the nav. aria-current="page" marks the page you are on.

Check the structure

  1. Find main and the heading inside it.
  2. Change only that heading’s words. Save and check the preview.
  3. Change one article’s description. Check again.

It is normal for the page to look much the same. CSS comes next.

3. Make the second page

  1. Save a copy of index.html as contact.html in the same folder.
  2. Change the copy’s title to Alex Rivers | Contact.
  3. Replace the content inside main with <h1>Contact Alex</h1> and a short paragraph saying a form will go here.
  4. Move aria-current="page" from Home to Contact. Keep only one.
  5. Save both files. Click between Home and Contact.

Try it

Read only your headings. Does the page still make sense?

Expected result: both pages open through the links. Home shows a latest release and three items. Everything still stacks vertically until you add CSS.

Check your understanding

Are head and header the same?

No. head holds page information such as the tab title. header is visible intro content in the body.

What is the difference between class and id?

A class can be used many times. An id is used once per page.
