Your first HTML page

By the end, you will have a real HTML file that opens in a browser.

1. What is a web page?

HTML (HyperText Markup Language) adds labels to plain text: this is a heading, this is a paragraph. The browser reads the labels and shows the page.

<h1>Alex Rivers</h1>
<p>Alex makes indie music.</p>

Alex Rivers

Alex makes indie music.

Why write HTML yourself? You can fix mistakes and make your own choices. Proper headings also help screen reader users move around a page.

2. Set up your work area

  1. Find OneDriveOpen L2 Digital → Web Development. Create it if missing.
  2. Make a folderInside Web Development, create website.
  3. Open in VS CodeFile → Open Folder → website.
  1. New fileIn Explorer, choose New File. Name it index.html, not .txt.
  2. Paste and saveCopy the starter below. Press Ctrl+S (Windows) or Cmd+S (Mac).
  3. PreviewRight-click index.html → Open in Integrated Browser.

Preview not changing? Save the file, then press Reload. Check you are viewing the file you edited.

index.html — the complete file

<!doctype html>
<html lang="en-GB">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Alex Rivers | Home</title>
</head>
<body>
  <h1>Alex Rivers</h1>
  <p>Alex is a fictional musician who makes upbeat indie music.</p>
</body>
</html>

3. Change one heading

  1. Select only Alex Rivers and type another name.
  2. Save. The large heading in the preview should change.
  3. Made a mistake? Press Ctrl+Z (Windows) or Cmd+Z (Mac). VS Code may add a closing tag for you, so check before adding another.

4. Paragraphs and section headings

h1 is the main heading. h2 is a section heading. Each paragraph needs its own p.

Add a paragraph. Press Enter inside one: nothing changes. Only a new <p> starts a new paragraph.

Try it

  1. In index.html, change the heading and first paragraph to a practice client’s.
  2. Add these lines inside body, before </body>.
  3. Change the title too. Save and check the preview.
<p>The new album is called Morning Light.</p>
<h2>Latest news</h2>
<p>Alex is preparing a new live show.</p>

Expected result: one main heading, two paragraphs, a “Latest news” heading with its paragraph, and your title on the browser tab. Plain styling is normal.

Project: create your own home page with a short client introduction. Keep a screenshot and a note on what HTML does (section 4.1).

Remember

HTML labels content with tags. Most elements have an opening tag, content and a closing tag. Save, then check the preview.
