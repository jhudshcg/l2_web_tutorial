Your first HTML page

By the end, you will have a real HTML file that opens in a browser.

1. What is a web page?

You have used web pages to read information, watch videos or buy things. Now you will make a simple one. A web page can start as an ordinary text file containing words and instructions about what those words mean.

HTML stands for HyperText Markup Language. You do not need to memorise the full name. “Markup” means labelling content: this is a heading, this is a paragraph, this is a link. Your browser reads those labels and displays the page.

In a Word document you might select text and choose a heading style. In HTML, you place a heading tag before the text and a closing tag after it. You will practise that below. There is no need to make the whole website today.

Two views of the same page

Code view: where you type HTML in VS Code.
Browser preview: where you see what a visitor would see.

They show the same file in different ways. Change the code, save it and check the preview. You edit the words in the code, not by typing over the browser page.

Later, CSS will control colours, spacing and layout. JavaScript can add behaviour. For now, concentrate on HTML and getting a heading and paragraph onto the screen.

Why learn to write HTML yourself?

If a heading is wrong or a paragraph is missing, understanding the code lets you find and fix it. You can make choices for your client instead of depending on a template or someone else’s changes.

Headings also help visitors scan a page. A fan looking for the latest release can spot “Latest news” quickly; short paragraphs make the details easier to read. People using a screen reader can use properly marked headings to move through the page.

2. Set up your work area

  1. Find your college OneDrive folder. Open L2 Digital → Web Development. This is your project work area; create Web Development there if it does not exist.
  2. Inside Web Development, create a folder called website. Keep your website code and images here. Your assignment document and slides can stay outside this folder, in Web Development.
  3. Open VS Code. Choose File → Open Folder and select that website folder.
  4. In VS Code’s Explorer panel, choose New File and name it index.html. The .html ending tells the software this is an HTML file. Check you have not added .txt at the end.
  5. Copy the complete starter below into the empty file. Save with Ctrl+S (Windows) or Cmd+S (Mac).
  6. Right-click index.html in VS Code’s Explorer panel or its editor tab, then choose Open in Integrated Browser. You can also use the editor’s Show Preview icon.

The preview can update while you edit. Save your work even when you can already see a change. If the preview looks old, save and click its Reload button. If the preview command is missing, ask your tutor to check your VS Code version; an external browser can also display the file. See VS Code’s HTML preview instructions.

Copying the starter is just setup. You will understand it by changing small parts. Leave the lines in head alone for now.

index.html — the complete file

<!doctype html>
<html lang="en-GB">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Alex Rivers | Home</title>
</head>
<body>
  <h1>Alex Rivers</h1>
  <p>Alex is a fictional musician who makes upbeat indie music.</p>
</body>
</html>

3. Get comfortable with one heading

Find this line in your code. The angle brackets are part of HTML; the words between them are your content.

A main heading

<h1>Alex Rivers</h1>

Read it as “start the main heading — Alex Rivers — end the heading”. <h1> starts it. </h1> ends it. The slash / marks the closing tag. The tags normally do not appear as text in the preview.

  1. Select only the words Alex Rivers between the tags.
  2. Type another practice name. Keep both tags.
  3. Save and look at the preview. The large heading should change.
  4. Change it back if you want to follow Alex’s example.

If you make a mistake, use Ctrl+Z (Windows) or Cmd+Z (Mac) to undo. VS Code may add a closing tag for you while typing: check before adding another one.

4. Add a paragraph, then another

A paragraph is a block of ordinary text. Each paragraph has its own <p> and </p>. Find the existing paragraph and change its words. Then add a new line underneath it, before </body>:

Two separate paragraphs

<p>Alex is a fictional musician who makes upbeat indie music.</p>
<p>The new album is called Morning Light.</p>

Save and check: you should see two separate blocks of text. Pressing Enter within a paragraph in your code does not normally create a new paragraph in the browser. The p elements do that job.

Add a smaller section heading

Put this below your two paragraphs, still inside body:

A section heading followed by a paragraph

<h2>Latest news</h2>
<p>Alex is preparing a new live show.</p>

h1 is the main page heading. h2 introduces a section within that page. Use headings to organise ideas, and paragraphs for the information underneath.

What the browser should roughly show

Alex Rivers

Alex is a fictional musician who makes upbeat indie music.

The new album is called Morning Light.

Latest news

Alex is preparing a new live show.

Your browser’s default font may look different. Check the order and separation of the content.

What do the other starter lines do?
  • <!doctype html> tells the browser to use modern HTML.
  • <html lang="en-GB"> wraps the document and identifies its language.
  • <head> contains information about the page. It is different from the visible <header> you will meet later.
  • charset="utf-8" supports characters such as £.
  • The viewport line helps the page use a mobile screen’s width.
  • <title> sets the browser-tab title.
  • <body> contains the visible content. Here, h1 is the main heading and p is a paragraph.

Try it

  1. Change the heading to a practice client’s name.
  2. Change the first introduction paragraph to explain who they are.
  3. Change the tab title too. Save and check the integrated browser preview.

Expected result: one main heading, two introduction paragraphs, a smaller “Latest news” heading and its paragraph. Your chosen title should appear on the browser tab. Plain styling is normal at this stage.

Check your understanding

Which part changes the browser tab, rather than the large page heading?

The title element changes the tab. The h1 element changes the visible main heading.

My changes do not appear. What should I check?

Save the file, use the preview’s Reload button, then check that the preview shows the same file you edited. Check its folder and filename.

Spot the error

Why does the paragraph look like part of the heading?

The name should be a main heading and the next sentence should be an ordinary paragraph. A closing tag is missing.

Broken example — find the mistake

<h1>Alex Rivers
<p>New album out now.</p>
Need a hint?

Match each opening tag to a closing tag with the same name. Which one has no partner?

Where should the missing closing tag go?

Choose the fix. If it is not right, read the clue and try again.

Show the corrected code and explanation
<h1>Alex Rivers</h1>
<p>New album out now.</p>

Now the heading and paragraph are separate elements. Browsers often try to recover from mistakes, so broken HTML may still display something; check the structure as well as its appearance.

Try the fix: Use your practice files to make the correction. Save, check the preview and explain what changed in your own words.
