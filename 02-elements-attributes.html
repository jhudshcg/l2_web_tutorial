Elements and attributes

An element gives content a job. An attribute adds information to an element.

Start with what you know

Open index.html from your OneDrive L2 Digital/Web Development/website folder in VS Code. Preview it with Open in Integrated Browser. Point to one heading and one paragraph in the code, then find them in the preview.

Last time you used <p>Some words</p>. The tags and their content together form an element. Now you will give some elements extra information, such as where a link should go.

1. Tags, elements and attributes

Example code

<a href="https://www.w3schools.com/">Explore W3Schools</a>
  • <a href="…"> is the opening tag.
  • Explore W3Schools is the content.
  • </a> is the closing tag. Notice the slash.
  • The whole example is an anchor element: a link.
  • href is an attribute name. Its quoted value is the destination.

Put attributes inside the opening tag. Use straight quotes " around values. Most elements wrap content; img, meta and link are void elements: they have no closing tag or inner content.

Make your first link in two small steps

First put this inside body: <p>Explore web examples</p>. Save and check: it is ordinary text.

Now replace that whole paragraph with <p><a href="https://www.w3schools.com/">Explore web examples</a></p>. Save and check again. The words are now a link; click them to test the destination, then go Back.

Changing the link’s text changes what visitors read. Changing href changes where they go. You can edit either without changing the other.

2. Add useful content

Keep your existing file. Add this inside body, after the introduction and before </body>.

index.html — add inside body

<h2>Latest release</h2>
<p><strong>Morning Light</strong> is Alex's new album.</p>
<h2>Explore Alex's work</h2>
<ul>
  <li>Morning Light — album</li>
  <li>City Walk — single</li>
</ul>
<p><a href="https://www.w3schools.com/">Explore web examples</a></p>

h2 introduces a main section. strong marks importance. An unordered list (ul) uses bullets; an ordered list (ol) uses numbers. Each item is an li.

Nesting means putting an element inside another. In the example, each li is inside ul. Close the inner element before closing the outer one. Indentation makes this easier to read.

Why use images—and describe them?

A cover image helps a fan recognise an album. A product image helps a customer understand what is being offered. Choose images that explain or support the content and fit the client’s style.

Some visitors use a screen reader, which turns page content into speech or braille. Useful alt text gives them the information a meaningful image provides. It can also help when the image does not load. An image used only as decoration needs an empty alternative, so it does not add distracting information.

Large image files can make visitors wait, especially on a slow mobile connection. Later, choose an appropriate image size and compress it without making it unclear. Add important product details as real text too, so visitors can read and enlarge them.

3. Add an image

  1. Create an images folder beside index.html.
  2. Save this original practice album image into it. If it opens instead, use your browser’s Save As option and keep the filename album.svg.
  3. Add this below the album paragraph.

index.html — image element

<img src="images/album.svg" alt="Morning Light album cover: a yellow sun above teal hills" width="600" height="400">

src gives the file path. Here it means “look in the images folder for album.svg”. alt gives a text alternative describing the image’s purpose/content. Use alt="" for a purely decorative image. width and height describe the image dimensions; CSS will make it shrink to fit later.

A path is a file’s location. Match spelling, capitals and extensions exactly. Use forward slashes /. A link to a page beside this file would be href="contact.html". A link to another website normally starts with https://.

Try it

Add a third list item. Change the link text so it describes the destination. Then briefly rename your image file: what happens in the browser? Restore the filename and refresh.

Expected result: headings, a three-item list, a working external link and a visible album cover. A wrong image path should reveal why matching filenames matters.

Check your understanding

In the image example, which is the attribute and which is its value?

src is an attribute name; images/album.svg is its value. The entire <img …> is an element.

Why is <p><strong>New!</p></strong> incorrect?

The elements overlap. Close strong before closing p: <p><strong>New!</strong></p>.

Spot the error

Why is this link not appearing as expected?

The link should say “Contact” and open contact.html. The destination starts with a quote but is not closed properly.

Broken example — find the mistake

<a href="contact.html>Contact</a>
Need a hint?

Attribute values in these examples have a quote on each side: name="value".

Which edit fixes the attribute?

Choose the fix. If it is not right, read the clue and try again.

Show the corrected code and explanation
<a href="contact.html">Contact</a>

The quotes enclose only contact.html. The > then ends the opening tag, and Contact is the visible link text.
