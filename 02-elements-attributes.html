<img src="images/cat-shades.png" alt="A ginger cat wearing black sunglasses" width="300" height="200">

Meet Milo

Milo is a very cool cat. He loves sunny windows.

Which image type?

.jpg: photos .png: graphics, transparency .webp: small photos and graphics .svg: simple logos and icons. Sharp at any size

Size images for the web

  1. ResizeMake it the size it will be shown.
  2. CompressShrink the file size without making it blurry.
  3. Name it wellLowercase, no spaces: cat-shades.png

Why describe images? Screen reader users hear the alt text. Everyone sees it if the image fails to load.

A link to a page in the same folder: href="contact.html". A link to another website starts with https://.

Try it

  1. Add a third list item.
  2. Make the link text describe where it goes.
  3. Change the image's alt text and width. Save and preview.
  4. Rename your image file, refresh and look. Then rename it back.

Expected result: headings, a three-item list, a working link and the cat picture. A wrong filename shows why exact paths matter.

Project: add useful text and an image you have permission to use. Start your asset table: filename, use, dimensions, format, file size, source, licence, date checked.

Spot the error

Why is this link not appearing as expected?

The link should say “Contact” and open contact.html. One quote mark is missing.

Broken example — find the mistake

<a href="contact.html>Contact</a>
Need a hint?

Attribute values have a quote on each side: name="value".

Which edit fixes the attribute?

Choose the fix. If it is not right, read the clue and try again.

Show the corrected code and explanation 
<a href="contact.html">Contact</a>

The quotes now surround only contact.html. The > ends the opening tag, and Contact is the link text.

Try the fix in your practice file. Save and check the preview.
